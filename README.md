# SEOTech
This is a professional software engineering agency website offering custom web/app development, UI/UX design, and cybersecurity services. The platform showcases technical expertise and project statistics to help businesses transform their digital vision into reality.

# SEOTech Website

A professional software engineering company website built with React 19 and Vite. This platform showcases services in web development, UI/UX design, and cybersecurity.

## 🚀 Features

- **Modern UI/UX**: Responsive design built with React and custom CSS.
- **Service Showcases**: Dedicated pages for Web Development, Designing, and Cyber Security.
- **Interactive Components**: Using Lucide React for modern, scalable icons.
- **Client Engagement**: Includes a landing page with project stats and an authentication/quote section.

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/)
- **Build Tool**: [Vite 8 (Beta)](https://vitejs.dev/)
- **Routing**: [React Router 7](https://reactrouter.com/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 📂 Project Structure

- `src/components/`: Reusable UI components like Navbar and Footer.
- `src/pages/`: Main page components (Landing, About, Services, etc.).
- `src/App.jsx`: Main application routing and layout.

## 🏁 Getting Started

### Prerequisites

- Node.js (Latest LTS recommended)
- npm

### Installation

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
